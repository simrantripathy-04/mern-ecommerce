MERN E-Commerce Website

A full-stack e-commerce web application built using the MERN stack, providing a complete online shopping experience with product browsing, cart management, checkout, address management, and order placement.

Features

- User registration and login
- Product browsing
- Product search and category filtering
- Add products to cart
- Update cart quantity
- Remove products from cart
- Address management
- Checkout functionality
- Order placement
- Stock management
- Responsive user interface

Technologies Used

Frontend

- React.js
- JavaScript
- HTML5
- Tailwind CSS
- React Router
- Axios

Backend

- Node.js

Installation

1. Clone the repository

git clone https://github.com/simrantripathy-04/mern-ecommerce.git

2. Install dependencies

Open the "Backend" and "Frontend" folders separately and run:

npm install

3. Configure environment variables

Create a ".env" file inside the "Backend" folder and add the required environment variables.

4. Start the backend

npm run dev

5. Start the frontend

npm run dev
